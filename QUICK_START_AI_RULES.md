# Quick Start: AI Custom Rules

## 🚀 Get Started in 3 Steps

### Step 1: Open the Rules File
```
book/Config/AIRules.txt
```

### Step 2: Add Your Rules
```
- Always be friendly and encouraging
- Keep responses concise
- Use examples when explaining concepts
```

### Step 3: Restart the App
Close and reopen the app to load your rules.

---

## ✅ Verify It's Working

### Check Console
Look for this message when app starts:
```
✅ Loaded 3 custom AI rules
```

### Test a Rule
1. Add: `- Always end responses with "Hope this helps!"`
2. Restart app
3. Ask any question
4. Verify response ends with "Hope this helps!"

---

## 📝 Rule Format

### Correct Format ✅
```
- Always be friendly
- Keep responses concise
- Use examples
```

### Incorrect Format ❌
```
Always be friendly (missing dash)
# - This is a comment (will be ignored)
(empty line - will be ignored)
```

---

## 💡 Example Rules

### For Casual Use
```
- Use a friendly, conversational tone
- Keep responses brief
- Use emojis occasionally 😊
```

### For Professional Use
```
- Use formal, professional language
- Provide detailed answers
- Include references when possible
```

### For Learning
```
- Explain concepts step-by-step
- Provide code examples
- Ask if I understand before moving on
```

---

## 🔧 Tips

1. **Start Small**: Begin with 3-5 rules
2. **Be Specific**: "Provide step-by-step instructions" not "Be helpful"
3. **Test Often**: Add one rule, test, then add more
4. **Use Comments**: Organize rules with `# Section Name`
