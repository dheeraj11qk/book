# Example 1: Code Output Question
Q: What will this Go slice code print?

**Short Answer:**
The first print shows length 8 and capacity 8. After append, the length becomes 9 and capacity increases to 16.

**Output Short Answer:**
The program prints: len 8 cap 8 and then len 9 cap 16.

**Full Answer:**
The slice s is initialized with 8 elements, so both <keyword>len</keyword> and <keyword>cap</keyword> are 8. When append(s, 8) is executed, the slice exceeds its current <keyword>capacity</keyword>. Go automatically allocates a new underlying <keyword>array</keyword> with larger capacity, usually doubling it. So the length becomes 9 and the capacity becomes 16. This demonstrates how slice growth works internally in Go.

**Code:**
```go
package main

import "fmt"

func main() {
    s := []int{1, 2, 3, 4, 5, 6, 7, 8}
    fmt.Println("len", len(s), "cap", cap(s))
    s = append(s, 8)
    fmt.Println("len", len(s), "cap", cap(s))
}
```

# Example 2: Implementation Question
Q: How do I use channels?

**Short Answer:**
Channels are used to communicate between goroutines. You create them with make() and send/receive data using the <- operator.

**Output Short Answer:**
This code sends the value 42 through a channel and prints 42 as output.

**Full Answer:**
<keyword>Channels</keyword> provide a way for goroutines to communicate and synchronize. They are created using `make(chan Type)` and support send (`ch <- value`) and receive (`value := <-ch`) operations. Channels can be <keyword>buffered</keyword> or <keyword>unbuffered</keyword>. Unbuffered channels block until both sender and receiver are ready. Buffered channels allow sending without blocking until the buffer is full.

**Code:**
```go
package main

import "fmt"

func main() {
    ch := make(chan int)
    
    // Send in goroutine
    go func() {
        ch <- 42
    }()
    
    // Receive
    value := <-ch
    fmt.Println(value) // Output: 42
}
```

# Example 3: Comparison Question
Q: What is the difference between slice and array?

**Short Answer:**
Array has fixed size. Slice is dynamic and more flexible.

**Output Short Answer:**
The array prints three fixed elements, while the slice prints four elements after append.

**Full Answer:**
An <keyword>array</keyword> in Go has a fixed size defined at compile time and is a value type. A <keyword>slice</keyword> is a dynamic, flexible view into an array and is a reference type. Slices can grow and shrink using `append()`. Arrays are rarely used directly; slices are preferred for most use cases. When you pass an array to a function, it's copied; when you pass a slice, only the slice header is copied.

**Code:**
```go
package main

import "fmt"

func main() {
    // Array - fixed size
    arr := [3]int{1, 2, 3}
    
    // Slice - dynamic
    slice := []int{1, 2, 3}
    slice = append(slice, 4) // Can grow
    
    fmt.Println(arr)   // [1 2 3]
    fmt.Println(slice) // [1 2 3 4]
}
```
