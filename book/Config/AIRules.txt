# Example 1: Conceptual Question
Q: What is a goroutine?

**Short Answer:**
A goroutine is a lightweight thread managed by the Go runtime. It allows concurrent execution of functions.

**Full Answer:**
A <keyword>goroutine</keyword> is a lightweight thread managed by the <keyword>Go runtime</keyword>. It enables concurrent execution without the overhead of OS threads. Goroutines are created using the `go` keyword and are multiplexed onto OS threads by the Go scheduler. They are extremely cheap (starting at ~2KB stack) and you can run thousands of them simultaneously. This makes Go excellent for concurrent programming.

**Code:**
```go
package main

import (
    "fmt"
    "time"
)

func main() {
    // Launch goroutine
    go func() {
        fmt.Println("Hello from goroutine")
    }()
    
    time.Sleep(time.Second) // Wait for goroutine
}
```

# Example 2: Implementation Question
Q: How do I use channels?

**Short Answer:**
Channels are used to communicate between goroutines. You create them with make() and send/receive data using the <- operator.

**Full Answer:**
<keyword>Channels</keyword> provide a way for goroutines to communicate and synchronize. They are created using `make(chan Type)` and support send (`ch <- value`) and receive (`value := <-ch`) operations. Channels can be <keyword>buffered</keyword> or <keyword>unbuffered</keyword>. Unbuffered channels block until both sender and receiver are ready. Buffered channels allow sending without blocking until the buffer is full.

**Code:**
```go
package main

import "fmt"

func main() {
    ch := make(chan int)
    
    // Send in goroutine
    go func() {
        ch <- 42
    }()
    
    // Receive
    value := <-ch
    fmt.Println(value) // Output: 42
}
```

# Example 3: Comparison Question
Q: What is the difference between slice and array?

**Short Answer:**
Array has fixed size. Slice is dynamic and more flexible.

**Full Answer:**
An <keyword>array</keyword> in Go has a fixed size defined at compile time and is a value type. A <keyword>slice</keyword> is a dynamic, flexible view into an array and is a reference type. Slices can grow and shrink using `append()`. Arrays are rarely used directly; slices are preferred for most use cases. When you pass an array to a function, it's copied; when you pass a slice, only the slice header is copied.

**Code:**
```go
package main

import "fmt"

func main() {
    // Array - fixed size
    arr := [3]int{1, 2, 3}
    
    // Slice - dynamic
    slice := []int{1, 2, 3}
    slice = append(slice, 4) // Can grow
    
    fmt.Println(arr)   // [1 2 3]
    fmt.Println(slice) // [1 2 3 4]
}
```
