```

1️⃣ [1-2 sentences - SPEAKABLE]

[3-5 sentences - DETAILED with <keyword> tags]

## 🎯 How to Use

### Interview Prep:
1. Ask question
2. Read Short Answer 3x
3. Practice saying it
4. Done!

### During Interview:
1. Recall Short Answer
2. Speak naturally
3. Use Full Answer if needed
4. Show Code if asked

### For Learning:
1. Read all three
2. Understand concept
3. Run code
4. Experiment
